# AI Orchestrator Module (`modules/ai`)

## Architectural Boundary
The cognitive backbone of NEXORA. Adheres strictly to the human-in-the-loop 3-step paradigm:
1. Receives natural language objective from user.
2. Ingests business profile context & available integrations.
3. Produces a transparent, staged execution plan for user review.
4. Never performs unilateral uncontrolled actions without user verification.
